# My LLM Apps

A portfolio of AI products built to demonstrate product judgement, reliable
agent design, measurable evaluation, human oversight and production-aware
delivery.

## Applications

### [RAG based Customer Support Operations Agentic System](apps/rag-customer-support-operations-agentic-system/)

A deployed, policy-grounded customer-support system for Returns, Exchanges and
Billing. It combines a three-agent architecture, managed conversation history,
cross-session memory, Agent Platform RAG, durable human-action workflows and a
private operations dashboard.

**Product themes:** trustworthy RAG, multi-agent orchestration, human-in-the-loop
operations, auditability, cost awareness and evaluation-led iteration.
